# docs

- `ARCHITECTURE.md`: the system as it is meant to be built. Read first.
- `decisions/`: one entry per decision that constrains future work, numbered, never edited after acceptance.
- `RUN_MANIFEST_TEMPLATE.json`: legacy run manifest from the Colab era; superseded by the manifest schema described in `ARCHITECTURE.md` section 5 and decision 0007.
- `history/`: records of earlier generations of the code, kept for reference, not for running.
